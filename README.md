# Modular-Program-in-Python-Spanish
Project Overview: A robust, interactive command-line application built in Python designed to demonstrate foundational programming principles, clean code modularity, and professional software engineering best practices.

Key Features & Technical Highlights:
Modular Architecture: Clear separation of concerns with independent utility and greeting functions defined at the top-level scope, avoiding nested or global side effects.

Type Hinting: Explicit parameter and return type annotations (e.g., -> float, -> None) to improve code readability, maintainability, and static type checking.

Professional Documentation: Comprehensive docstrings written in technical English following industry-standard formats (Args, Returns).

Robust Input Validation: Strict integer validation for menu navigation and float handling for mathematical operations to prevent runtime crashes on unexpected user input.

Interactive Control Flow: Continuous execution loop using while True paired with a clean exit mechanism (break) and error handling for invalid options.
